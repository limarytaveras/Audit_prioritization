# Version 3.0.0 public portfolio edition

Reimplemented the supplied prototype for process prioritization with synthetic data. Added explicit IDs, fixed scales, cutoff-aware events, incidents, current-snapshot filtering, separate historical model estimates, per-job effort and shortfall reporting. Added tests, examples and public documentation.

This is a revised implementation, not an unchanged copy. Original office documents, office ranking, free-form aliases, spreadsheet export and implicit technology-name rules are excluded. The optional model no longer alters the expert index.
