## Texto para tu portafolio

Desarrollé un prototipo en Python para priorizar procesos auditables mediante riesgos, hallazgos, incidentes y cobertura. Implementé puntuaciones explicables, controles temporales, selección según capacidad y pruebas automatizadas. La versión pública utiliza exclusivamente datos sintéticos e incluye un modelo experimental de selección histórica con evaluación temporal.
